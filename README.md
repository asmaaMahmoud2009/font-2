# Quote Generator ✨

## فكرة المشروع

Quote Generator هو تطبيق تفاعلي بسيط يقوم بعرض مقولات عشوائية مع اسم قائلها.

يمكن للمستخدم التفاعل مع التطبيق من خلال:

- عرض مقولة جديدة بشكل عشوائي.
- نسخ نص المقولة إلى الحافظة.
- تغيير لون خلفية الصفحة مع كل مقولة جديدة.
- تغيير لون الكارت مع كل مقولة جديدة.
- التصميم متجاوب مع الموبايل والكمبيوتر.

## التقنيات المستخدمة

- HTML
- CSS
- JavaScript (ES6+)

## مميزات المشروع

### 1. مقولة جديدة

عند الضغط على زر **مقولة جديدة** يتم عرض مقولة عشوائية مختلفة مع اسم القائل.

### 2. نسخ المقولة

عند الضغط على زر **نسخ المقولة** يتم نسخ نص المقولة واسم القائل إلى Clipboard، وتظهر رسالة تؤكد نجاح عملية النسخ.

### 3. تغيير الألوان

مع كل مقولة جديدة يتم تغيير لون خلفية الصفحة ولون الكارت بشكل عشوائي.

### 4. Responsive Design

التصميم يعمل بشكل مناسب على:

- الكمبيوتر.
- اللابتوب.
- التابلت.
- الموبايل.

## طريقة تشغيل المشروع

لا يحتاج المشروع إلى Backend أو قاعدة بيانات.

يمكن تشغيل المشروع عن طريق فتح ملف:

```text
index.html
```

في المتصفح.

ويُفضل تشغيله باستخدام **Live Server** في VS Code.
